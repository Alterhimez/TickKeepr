# TickKeepr

A pair of Forge 1.16.5 mods for offline and unloaded-chunk progression.

## Overview

This repository contains two complementary mods:

- TickKeepr — replays tickable block entity activity when chunks unload and reload, simulating the progress that happened while the world was offline.
- TickKeepr Bottle — credits offline real-world time into Time in a Bottle items when you log back in.

Both are built for Forge 1.16.5 and are intended for modded packs that want machines and time-based progression to keep working while the game is closed.
